# SoftTeamGlobal — Analytics Dashboard

Веб-приложение для мониторинга финансовых показателей компании и аналитики по департаментам. Проект предоставляет инструменты для отслеживания выручки, расходов, чистой прибыли, загрузки ресурсов (utilization) и состава команд.

---

## Основные возможности

* **Финансовый дашборд:** Визуализация ключевых KPI (Revenue, Expenses, Net Profit, Profit Margin) и динамики денежных потоков за выбранный период.
* **Аналитика департаментов:** Обзор показателей команд, уровня утилизации сотрудников и распределения финансовых результатов.
* **Детальный дашборд департамента:** Просмотр подробных данных по конкретному отделу, включая квартальную финансовую динамику и список сотрудников с их грейдами и навыками.
* **Интерфейс и темы:** Поддержка светлой и тёмной темы оформления с сохранением состояния.
* **Интернационализация (i18n):** Поддержка мультиязычности (RU / EN) с использованием библиотеки Transloco и сохранением выбранного языка в `localStorage`.

---

## Технологический стек

* **Frontend:** Angular (версия 18+), TypeScript, HTML5, CSS3 (Custom Properties, Glassmorphism).
* **Управление состоянием и данными:** Angular Signals, `httpResource` (`@angular/common/http`).
* **Визуализация данных:** Chart.js.
* **Локализация:** `@jsverse/transloco`, `@jsverse/transloco-keys-manager`, `@jsverse/transloco-persist-lang`.
* **Сборка и инструментарий:** Angular CLI, Prettier.

## Быстрый старт

### Требования

* Node.js (версия 18.x или выше)
* npm (версия 9.x или выше)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/soft-team-global.git
cd soft-team-global

```


2. Установите зависимости:
```bash
npm install

```



### Запуск в режиме разработки

Для запуска локального сервера разработки выполните:

```bash
ng serve

```

После завершения сборки откройте браузер и перейдите по адресу `http://localhost:4200/`. Приложение автоматически перезагружается при изменении исходных файлов.

---

## Работа с локализацией (Transloco)

В проекте используется автоматический экстрактор ключей перевода.

Для извлечения новых ключей из шаблонов в файлы `public/assets/i18n/*.json` выполните команду:

```bash
npm run i18n:extract

```

---

## Сборка для Production

Для создания оптимизированной производственной сборки выполните:

```bash
ng build

```

Готовые файлы проекта будут помещены в директорию `dist/`.
